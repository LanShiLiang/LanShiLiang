## 精选项目

### 🎮 AI Game Lab · 网页游戏实验室

一个可扩展的 JavaScript 游戏大厅，把独立玩法、资源管理、浏览器交互和部署串起来。目前收录轨道闪避、运输船 FPS 与逐浪竞速；游戏按清单接入，独立页面运行，支持键盘与触屏。

- **逐浪竞速 / APEX Racing**：Three.js 3D 赛车，两条赛道、漂移与氮气、个人和队伍竞速。人机模式直接在浏览器运行，在线房间最多 16 人；Node.js / WebSocket 服务采用权威模拟与快照插值。
  [在线试玩](https://lslzqco.cn/ai-game-lab/games/apex-rush/) · [在线房间](https://lslzqco.cn/ai-game-lab/games/apex-rush/?online=1) · [公开源码](https://github.com/LanShiLiang/apex-rush)
- **运输船 / Freight Fire**：Three.js 网页 FPS，支持 4v4 / 8v8 人机对战。实践骨骼动画、枪械反馈、物理布娃娃和可恢复的资源加载；浏览器与本地 LAN 服务复用战斗模拟。
  [在线人机试玩](https://lslzqco.cn/ai-game-lab/games/freight-fire/) · [公开源码与本地开服说明](https://github.com/LanShiLiang/freight-fire)

运输船公网入口提供人机模式，局域网对战需自行运行源码中的本地服务。游戏代码与第三方素材的权利说明见各仓库。

### 📊 K Line Analyzer · 浏览器量价分析工具

Chrome Manifest V3 扩展，用可解释的规则分析公开 OHLCV 数据，在侧边栏展示阶段、信号、依据与图表。优先支持 Binance 和同花顺，也提供 TradingView 被动数据兼容路径；分析与配置保留在本地浏览器。

技术实践：**TypeScript、MV3、站点数据适配、Lightweight Charts、中英文界面、真实站点端到端验证**。

[Chrome 应用商店](https://chromewebstore.google.com/detail/gjihlpjpeficifemdpenbmamkfgnkkeo) · [公开源码](https://github.com/LanShiLiang/Chrome_K_line_analyzer)
